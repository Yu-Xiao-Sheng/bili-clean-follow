# Bili Clean Follow  (B站关注列表清理工具)

A tool to analyze, rank and clean up your Bilibili follows: stale, inactive,
duplicate or low-value accounts.

## Features
- Fetch your Bilibili follows (via login cookies)
- Analyze each follow (last activity, recency, content relevance)
- Classify each into: keep / review / remove
- Export a human-readable review list (md/csv)
- Safe by default: dry-run first, apply only after explicit confirmation
